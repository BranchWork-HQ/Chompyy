# CLAUDE.md

## Pull requests and commits

- Do not add "🤖 Generated with [Claude Code](https://claude.com/claude-code)" (or any "Generated with" line) to pull request descriptions.

## Writing

- Every string a user reads (cards, notifications, hook messages, CLI output) follows [cli/STYLE.md](cli/STYLE.md): action first, two lines max for a notification, five items max, no internal rule IDs.
